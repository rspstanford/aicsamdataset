This is a spreadsheet containing a dataset of federal criminal cases from federal district courts around the country that somehow involve AI-generated or AI-morphed child sexual abuse material (CSAM) or obscene sexual depictions of children. It was collected in support of legal research. The spreadsheet links to the CourtListener dockets for each case so that anyone viewing the dataset can locate the court filings in a particular case. The original dataset was last updated on Aug. 2, 2026, and added to GitHub the same day. Anyone is invited to make use of this dataset, which I believe is the most comprehensive public list of federal criminal AI-CSAM cases collected to date.
